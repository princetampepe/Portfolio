# Prince Christian T. Tampepe Portfolio

React + Vite portfolio website with a light glassmorphism UI.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

This project is ready for Vercel deployment as a Vite app.

1. Push the repository to GitHub, GitLab, or Bitbucket.
2. Import the repository in Vercel.
3. Use the default settings, or set them explicitly:
	- Build Command: `npm run build`
	- Output Directory: `dist`
4. Deploy.

You can also deploy with the Vercel CLI from the project root:

```bash
npx vercel
```
